# PC 更新日志

仅记录保险库桌面端的功能与修复。Android 客户端变更在其独立仓库维护。

---

## 4.6.7 - 2026-10-07

### 新增与优化
- 锁定后释放保险库密钥、解密条目和界面缓存，等待正在执行的任务安全结束；再次解锁重新打开保险库会话。
- 设备记录新增移除入口和二次确认：撤销应用内同步授权并持久移除记录，禁止移除当前设备，不删除对方保险库。
- 移除删除记录清理功能；永久删除标记始终保留，旧追加块由现有压缩功能回收。
- 设备记录仅显示签名有效且当前授权有效的设备，隐藏未授权、已撤销、已过期及异常记录。
- 登录等待及密码验证按钮使用三点从左到右依次放大并恢复，登录成功后仅绘制对勾；为动画保留完整空间，避免裁切。
- 统一自动填充候选排序：综合网址、关联应用、标题和关键词，支持大小写、全角字符与相近名称匹配；保留来源校验，候选相似不会自动授予填充权限。
- 支持自定义字段匹配、手动指定字段用途及加密保存填充关联；排除规则和关联信息随保险库同步。
- 新增按云端目标开启的远端更新提醒：首次检查建立基线，后续更新去重提醒，可稍后处理；提醒本身不下载、不覆盖保险库。Android 在应用前台且保险库解锁时检查，PC 在应用运行且保险库解锁时检查。
- 设备记录入口统一移入安全设置，移除同步页／库维护中的独立入口。
- 设备名称自动使用系统设备名称；安卓无法读取时回退到机型，PC 使用计算机名。打开页面及返回前台时刷新，本机改名后通过保存和同步更新其他设备上的记录。
- 精简设备页面，仅展示名称、活动和已认证授权记录，不再提供应用内昵称设置。

## 4.6.5 - 2026-10-02

### 修复
- 修复敏感操作二次验证可以无限次重试。此前该对话框只 shake 一下并提示「主密码不正确」，不计数、无退避、无冷却，可无限重输。这个缺口在桌面端比移动端更危险：`verify_password` 的快速路径走 `hmac.compare_digest` 而不跑 Argon2id，单次成本接近零；解锁对话框每次都跑完整 KDF（64 MiB, t=3）本身就有天然节流。现在二次验证与解锁页共用同一份计数记录，行为与安卓 `MasterPasswordDialog` 逐条对齐。
- 修复二次验证记满上限后应用仍不锁定。库本来处于解锁态却连续猜错主密码，持机者很可能不是用户，此时应立即降级为锁定态。
- 修复冷却倒计时不可靠。此前剩余秒数靠对话框内存里的计数器逐秒自减，会与真实截止时间漂移：窗口最小化、系统挂起或睡眠之后两者对不上，后台暂停还会让冷却被提前判定结束。现改为按持久化截止时间重算，定时器间隔与安卓侧 200ms 轮询一致。
- 修复冷却退避期间没有任何可见反馈。现在退避期同样显示剩余秒数。
- 修复一个旧窗口能清掉另一入口刚产生的冷却。UI 不应修改安全状态，现改为按当前账户判定恢复哪些控件。
- 修复 `record_password_failure` 的读-改-写竞态。主程序与常驻的 browser_host 进程并发失败时可能都读到旧值，导致冷却轮次只加一次而非两次——结果比预期更宽松。
- 修复通行密钥条目无法使用标签。标签是纯元数据，但此前在加载、导入、标签索引与右键菜单四处都被排除。条目本身仍不可编辑（密钥材料只由 Credential Provider 写），但用户需要能筛选与整理它们。
- 修复条目编辑器的延迟自适应可能在对话框销毁后触发。若在事件循环处理该回调之前关闭编辑器，PySide 会抛「内部 C++ 对象已删除」。
- 修复自动更新只有下载进度，安装阶段完全不可见。安装器的退出码此前被直接丢弃，应用无从得知安装成功与否，失败对用户完全不可见。现在分下载、校验、安装、完成四个阶段展示，只有安装器确认成功才退出程序。
- 修复英文界面残留中文。自动同步的状态串是持久化下来的中文原文，渲染时未过翻译；本地备份的「备份设备（VOL-xxxx）」只翻译了前缀，卷名与括号都是裸值。
- 修复 CSV 导入丢标签：标签判断误写成只保留登录类型，把 Wi-Fi、银行卡、API 密钥等类型的标签全丢了。

### 变更
- 云端上传改走一次流式发布，消除两段式写入的窗口。弱 ETag 服务器补上内容级 CAS：合并流程会原地改写快照路径，因此单独留存下载当时的 SHA-256 作为「远端副本」凭据。用户显式「上传覆盖」时跳过全部闸门无条件发布。

## 4.6.4 - 2026-09-30

### 修复
- 修复主机侧点「关闭页面」完全没有反应：该路径要经工作区回到传输站入口，而连接方页面从未被登记进工作区，取引用时抛 `AttributeError`，被 Qt 静默吞掉。
- 修复连接方对「对方已关闭传输连接」完全失明：原先轮询传输条目时把异常一律吞掉，对方关站后连接仍被视为在线，发送区留在页面上、按钮还写着「断开连接」。现改为连续失败到阈值即判定断开并统一收口。
- 修复断开后发送内容区只是被禁用、仍占着页面，看起来还能输入其实发不出去。主机侧（本地结束／对方结束／连接超时）与连接方（对方关闭／连接失败）现在都会真正收起发送区，按钮同时切成「关闭页面」，传输记录保留供查看。
- 修复连接超时自动断开后没有触发断开收尾，超时路径下发送区与按钮状态都不对。
- 修复局域网同步页在连接方侧完成后不显示同步结果：结果卡原先还要求「别的通道没在忙」，而同步结束标志归零与结果写入之间存在一个刷新窗口，两侧条件会同时不成立，结果总是丢给「已关闭」分支。
- 修掉三处中文串里被插入的多余空格（传输站说明、导出授权说明、导出确认弹窗）——它们同时是英文翻译表的查询键，多一个空格就查不到、英文界面会漏出中文。
- 顺带清理 `ui/sync_pages.py` 中已无引用的导入，并统一该文件的书写风格。

### 变更
- 断开前增加二次确认：同步中断开放弃的是本次合并与回传，可能停在半合并状态，代价高于传输中断（传输只丢个别条目）。主机侧停站、连接方断开、以及文件传输页两处都改为先确认，与安卓端口径一致。
- 会话结束后的出口统一叫「关闭页面」：同步页与传输页共用这一措辞，断开后再点「断开连接」已经没有对象可断，留下的那颗按钮实际语义就是关掉本页面。

## 4.6.3 - 2026-09-29

### 修复
- 修复「检查更新」点了没反应：更新弹窗的构造函数因缩进丢失落到模块层级，`UpdateDialog` 实际继承了父类的两参签名，而调用处传的是三个参数，构造时抛 `TypeError`。异常发生在 Qt 槽里会被 PySide6 静默吞掉（窗口版构建还会连 stderr 一起丢掉），于是按钮变回原状、什么弹窗都没有——**应用内更新通道自 2026-08-20 起一直是失效的**。
- 修复共享保险库上「设备授权记录无法读取」导致**所有设备都无法通过密钥认证**的问题。旧版 Android 曾把一个没有定义的权限位写进授权记录并签入保险库；本端按 3 位严格校验时，整份授权清单都会读不出来，于是每台设备都认证失败。现改为保留记录原值（签名与数据均保持有效），未定义位不授予任何权限，**存量库无需迁移或重新录入**。
- 修复局域网断连后的矛盾状态：界面保留「已连接，等待同步或传输…」的文案，同时「建立传输站」按钮又恢复可用。根因是收尾时先刷状态、后停服，而配对记录只在停服时才清空，写进去的「已连接」此后无人刷新就被冻结。现改为先停服、再复位状态、最后才露出入口，并把自动收起过的二维码/提示放回。
- 修复文件传输跑完后局域网三档滑块被永久禁用：传输中标志原先只在初始化时置零、停服时不清，导致「有任务进行中」一直成立。现已在停服时一并复位传输与同步进度。
- 修复模块卡片的删除叉号点击后变成一坨粉色圆角块、叉号消失：铺停靠底色时先把画笔设成无笔画，叉号又从画笔继承了它，而改颜色/线宽改不回线条样式，两条叉号线于是什么都没画。现改为单独新建实线画笔，底色与叉号可以共存。
- 悬浮按钮改为**半透明**：原先的毛玻璃在条目列表上看不出效果——背景是平铺浅色底，高斯模糊半径稍大就把行完全抹平、糊完与原背景同色；半径调小又被上方玻璃色的不透明度压到肉眼不可见（实测对比度只剩 255 级中的 8～20），观感就是「只有透明」。而它每帧都要把整个滚动视口重新抓取一遍再做模糊，且跟着滚动条逐格触发，代价不小。现去掉这层模糊，改用干净的半透明表面，并一并去掉这层无谓的逐帧重渲染。
- 跨端向量新增一条「未定义权限位仍可读」用例（`permissions=15`），覆盖解码、验签、逐字节复现与「bit3 不授权」四项性质；两端测试运行器改为遍历全部用例。

### 变更
- 截屏保护改为**默认开启**（「允许截屏」默认关闭）：保险库内容不应默认出现在截图、录屏、投屏里。已显式保存过的取值（新键或旧的反向键）一律沿用，不因改默认值而改变。

## 4.6.2 - 2026-09-26

2026-09-27 重发：x64 安装包包含已签名的 Windows Passkey Provider。首次安装前，用户需核对同一 Release 提供的 `FAE-Vault-CodeSigning.cer` 并自行将其加入 Windows `TrustedPeople`；安装器不会静默添加信任。公开证书和安装包均列入 `SHA256SUMS.txt`。便携包不安装系统级 Provider。

2026-09-27 再打包：浏览器连接程序与主程序共用运行库，安装包体积约减半；修复安装后设置页导入联系人信息时报错而无法启动的问题，并改善 Windows 原生程序自动填充的触发速度及 Epic 登录框兼容性。

2026-09-27 云端硬盘修复：下载远端保险库时，临时副本改放本机临时目录，避免在云盘或移动硬盘的保险库旁生成 `.download-*.tmp` 文件并被云盘同步；完成、失败或取消后清理临时副本。

### 变更
- 深色主题的强调色由紫调（色相 238°）改为与浅色同族的蓝（色相 217–222°）：`accent` / `accent_hover` / `accent_soft` / `accent_text` / `accent_text_hover` 与主按钮整体换色；深色主按钮仍是纯色（仅浅色用深蓝渐变），与原结构一致。
- 局域网不再是三级下拉菜单：收敛为单个入口，打开后页面顶部是三档胶囊滑块（建立传输站 / 局域网同步 / 文件传输），切档只替换下方内容、不换页头，默认停在「局域网同步」；同步或互传进行中滑块禁用，被其他设备连上时自动切到对方使用的通道档位。
- 底部通知占位条移除，改为内容区上方的悬浮通知条：顶部居中、宽度上限 560px、反色胶囊（浅色主题深底浅字）、停留 4 秒后淡出（进入 180ms / 退出 240ms），点击立即关闭，不再占用底部布局高度。
- 设置页移除「云端同步」分组：启用开关与云端关联都由「云端同步」页自带；同时删掉主窗口里那一份从未接线的同类处理（`_on_cloud_sync_toggled` / `_refresh_cloud_sync_controls`，其 `_cloud_sync_toggle` / `_cloud_sync_btn` 全仓库从未赋值，写的是旧 config key）。总开关收敛到该页的 master 开关后，菜单入口改为常驻，否则关闭后就再也进不去那个页面。
- 分类栏底部的三横线操作面板入口移除；导入、导出、整理功能整体并入顶部迷你栏的“更多功能”菜单。
- 顶部“同步”下拉改为“更多功能”，按“同步”“库维护”两组二级菜单归类：同步下含导入导出（4 项导入 + 4 项导出）、本地备份、局域网（建立传输站 / 局域网同步 / 文件传输）、云端同步；库维护下含重复条目合并、相同服务合并。
- 手动“数据库清理/压缩”入口移除，改为与安卓端对齐的自动维护：启动与每次解锁后台回收临时文件、清理过期回收站条目，并在清理出条目后立即压缩；媒体提交后按独立阈值（距上次压缩 ≥10 分钟且增长 ≥32MB）机会式压缩，避免追加写文件的虚胖。
- 安全中心、回收站、设置、重复条目对比、相同服务处理、局域网传输站/连接、本地备份和云端同步改为编辑器工作区内的持久标签；点击条目始终回到固定的“条目详情”标签，其他功能标签及其状态保留。
- 功能标签为单实例，关闭前按运行状态二次确认，并在关闭、锁定、切换账户或退出时统一清理后台任务与敏感会话。
- 同步、安全中心、回收站、设置改为在顶部迷你栏内右对齐；右侧详情卡顶部与左侧搜索框顶部对齐。
- 编辑器工作区标签栏改用窗口背景色，选中标签为内容背景色、顶部圆角并加粗强调色文字，不再画底部分割线，与下方内容连成一片；相邻标签之间只画中间一小段浅色竖分割线。
- 编辑器功能页的内容边距统一为 `PAGE_MARGINS`（20px）：设置页原先 28px 的左右边距、云端同步页缺失的边距、相同服务处理页缺失的边距一并归位，页面之间不再各写各的数值。
- 品牌蓝配色并入浅色主题并成为默认外观，设置中的“品牌蓝”选项移除（保留“跟随系统/浅色/深色”）；历史配置中的 `brand_blue` 读取时自动迁移为 `light`，视觉保持不变。
- 条目列表栏底部的「新增条目」不再铺满整行、也不再单独占一行：改为浮在条目之上的贴底居中按钮，宽度随内容自适应（`_FloatingAddButton` 复用详情页底部操作条的贴底居中逻辑，仍由列表卡片托管）。配色不另起一套——它和详情操作条里的「编辑」一样走通用 `QPushButton` 规则，底色、描边与悬停/按下反馈完全一致；原先只为它保留的 `GhostBar` 样式一并移除。

### 修复
- 关闭传输站时若临时 TLS 文件被占用（Windows 上杀软/索引器常占句柄），`SyncServer.stop()` 会抛出 `PermissionError` 并中断整个停止流程，后面的传输目录清理与结果收尾全被跳过。临时文件删除改为尽力而为并记录日志。
- 打开云端同步后控制台被 `RuntimeError: libshiboken: Internal C++ object (PySide6.QtGui.QAction) already deleted` 刷屏：控制器挂在主窗口上、页面销毁后仍在发信号，视图回调于是打到已删除的控件（「更多操作」菜单里的 QAction 等）。订阅现在统一加一层「视图是否还在」保护，捕获后自动断开订阅，不再反复报错（沿用 `_set_backup_status` 的同一手法）。
- 安全中心按条目自身类型列出结果，左侧列表却按当前类目筛选，因此跨类目点击（如左侧停在登录时点 WiFi 结果）会静默失败、无法跳转。跳转现在会先解除挡住该条目的筛选（搜索词 / 标签 / 类目 / 安全筛选）再选中；同类型跳转不动用户已有的筛选。
- 建立传输站后没有「关闭传输站」入口，一旦开站只能关掉整个局域网标签页。现在会话内提供该按钮：停服、放开自动锁定阻断、收起会话界面并让入口重新可用；会话进行中会先二次确认。
- 局域网「建立传输站」档位没有任何可点击入口：菜单收敛成单个「局域网」后，原先由菜单项直接触发的建立流程失去入口，该档位是空面板。现在档位自带说明与「建立传输站」按钮，会话结束后入口重新可用，同一页可再次建立。
- 云端同步各入口被 `can_start` 挡下时全部静默返回，界面上表现为「点了没反应」，分不清是后台在忙还是按钮坏了；现在会说明原因（正在加载设置 / 已有任务进行中 / 后台自动同步中 / 上一次会话尚未结束）。
- 云端同步检测途中关联被清掉时 `_pull_and_preview` 静默返回、busy 位永真：界面卡在「正在检测云端保险库数据…」且所有操作按钮变灰。现在会收尾并提示关联已失效。
- Mermaid 会把负宽高写进 SVG（文本量测相减得到负宽），Chromium 因而逐条打印 `<rect> attribute width: A negative value is not valid.` 刷屏控制台；渲染前安装属性夹取守卫，把负的 `width`/`height` 归零（负宽高的 `<rect>` 渲染结果本来就是 0），视觉不变且日志干净。
- 设置中的“回收站保留天数”此前完全不生效：`purge_expired` 已定义但全仓库无调用点，过期条目从未被清理。现在每次解锁都会执行过期清理，并顺带回收过期删除日志，避免其线性增长。
- 临时文件回收此前只挂在手动清理按钮上，崩溃残留的媒体导入暂存（`import-*.tmp` / `bytes-*.tmp`）与中转文件长期不被回收；现在启动与解锁时自动清理，并覆盖媒体目录，只回收超过 24 小时的暂存孤儿。
- 登录页主密码错误时对话框会被错误提示撑高（解锁按钮随之下移且不会复原）：提示区改为预留两行固定高度，错误、冷却与等待三种状态的对话框尺寸完全一致。
- 登录页解锁等待动画从“忘记密码”下方的独立一行移到解锁按钮内部，等待时按钮显示旋转指示与“正在解锁…”，不再额外占用行高。
- 登录页英文界面下错误提示中英混排（如“主密码不正确 (4 attempts remaining)”）：现在先翻译正文再套用动态文案模板。
- 密码失败退避期间输入框与解锁按钮仍可交互（密码框回车会直接触发 `accept()`），可能叠加第二次校验线程；退避期间现在禁用输入。
- 修复 `#Primary`/`#Danger` 按钮禁用态与正常态完全同色（objectName 规则优先于 `QPushButton:disabled`），冷却或等待中的按钮看起来仍可点击。
- 关闭本地备份页后，主窗口仍持有已销毁的状态标签，导致定时备份检查抛出 `Internal C++ object already deleted`；现改为失效后自动摘除引用。
- 修复安全中心按分类打开条目列表时向 `QListWidgetItem.setSizeHint` 传入 `None` 引发的 `TypeError`。
- 修复安全中心“在主列表查看”以 lambda 建立唯一连接时 Qt 报 `unique connections require a pointer to member function` 的告警。
- 修复详情卡上边缘的圆角边框线被标签栏覆盖：卡片内边距改为与 1px 边框等宽（1px），上边缘边框恢复连续。
- 切换主题后条目详情顶部卡片仍是旧主题的底色与描边，要重选一次条目才更新：卡片把 `surface_alt` / `border` 直接写进了控件级样式表，而控件级样式表在切换主题时不会被重算（全局样式表只覆盖它没声明的属性，这里却是全被声明了）。现在这些配色交回全局样式表（`QFrame#DetailTitleCard` 里本就有对应规则），控件级样式表只留全局样式表表达不了的类型强调色左边框。同样是控件级样式的过期提示条与「已泄露」字段标签，一并改为 objectName / 属性选择器。
- 条目列表、回收站列表与安全中心结果列表的滚动此前是 Qt 默认的按行滚动：行高固定 96px，每滚一格正好跳过一整行，滚动前后行位置完全重合、只有内容变了，看起来是「原地换皮」而不是在滚动。三个列表现在都改走逐像素滚动（`ScrollPerPixel`），能停在半行位置；行高固定 + `setUniformItemSizes(True)` 下位置计算仍是常数级，实测绘制次数与耗时不变（同样 30 步各 180 次重绘）。

- 新增 NAS 与自定义 WebDAV 云端同步，支持真实连接验证、后台上传下载、上传后读回校验和 LWW 合并。
- WebDAV 密码使用当前 Windows 用户作用域的 DPAPI 加密保存。

- 新增安全笔记、服务器和自定义类别。
- 新增可自由组合、排序并设置敏感属性的条目模块。

### 改进
- 浏览器凭据严格按 HTTPS Origin 匹配；列表不返回密码，选择后再次校验条目 ID 和来源；宿主会随自动锁定超时清除会话。
- 保险库写入增加跨进程锁、文件修订检测和条目版本检查，主程序可自动刷新浏览器宿主保存的数据，避免旧会话覆盖新数据。
- 云端同步入口改为按保险库独立启用：首次启用需验证主密码并确认风险，启用后的同步操作不再重复验证；重新关联需验证主密码，取消关联需验证主密码并二次确认。
- 云端硬盘和 NAS 关联已有数据时可选择同步合并或强制覆盖；默认同步统一为拉取、LWW 合并、并发校验、上传和读回校验。
- 云端硬盘新文件默认命名为 `vault_用户名.pmv`，并清理 Windows 文件名非法字符。
- 云端硬盘关联改为目录选择：优先复用同名文件，单个旧命名文件自动复用，多个文件时要求用户明确选择，空目录二次确认后才创建。
- 云端硬盘记录上次成功同步摘要，打开页面及同步时检测文件修改和删除；删除后默认同步不会自动重建，远端修改会进入拉取合并流程。
- 云端同步页签、面板、输入框、状态和进度条补充专用深浅色主题样式。
- 动态码模块新增摄像头和本地图像二维码识别，并在多二维码图片中提供明确选择。
- 银行卡与证件模块新增摄像头/本地图像 OCR；地址模块可按需读取 Windows 当前定位。
- 模块中的动态码参数、Wi-Fi 加密方式、数据库类型和证件类型改为下拉选择；关联程序可从运行中程序选择，图片模块支持放大预览。
- Wi-Fi 模块新增摄像头扫码与本地图像识别导入，多二维码图片可按 SSID 选择；开放网络导入会清除旧密码。
- 复合自定义模块不再保存银行卡、SSH 等卡片中的空白占位字段；图片模块改为缩略图网格，支持编辑页添加、单图点击预览和右上角删除。
- 银行卡与证件图片画廊同步统一为点击缩略图放大、右上角单图删除和末尾添加图片，并保留全部图片 OCR 识别填充。
- 自定义内容中的银行卡和证件模块新增持久化图片条目；相机或本地图像导入后立即显示缩略图并自动 OCR，支持点击预览和右上角单张删除。
- 所有密码字段及用户标记为敏感的普通字段支持隐藏/显示，并补充无摄像头、无定位权限、异常图片、重复图片和识别空结果处理。

- 云端配置按保险库谱系隔离，切换账户不会复用其他账户配置。
- 安全笔记纳入类型级敏感信息二次验证范围。

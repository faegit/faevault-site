# 保险库 Android 隐私政策

**生效日期：2026-09-23**
**适用版本：4.5.0 及以上**

本隐私政策说明保险库 Android 客户端在运行过程中如何处理数据、使用系统权限以及与外部服务通信。使用本应用即表示你已阅读并理解本政策所述的数据处理方式。

---

## 一、基本原则

保险库是一款本地优先的密码与凭据管理工具。本应用不提供开发者托管的账户系统或云端保险库，不集成广告、用户行为分析、遥测统计或自动崩溃上报服务。

保险库内容默认仅保存在你的设备中。除你主动启用局域网同步与文件传输、导入导出、自动填充、Passkey、在线泄露检测、检查更新，或主动配置云端同步（含自动同步）外，本应用不会主动将保险库数据发送至其他设备或服务。

## 二、处理的数据

本应用可能处理以下由你主动录入、导入、生成或选择传输的数据：

- 登录账号、密码、动态码密钥、银行卡、证件、Wi-Fi、服务器、安全笔记及自定义模块；
- 附件文件，包括你选择添加的图片、文档及其他任意类型文件，附件随保险库加密存储并参与同步；
- 关联应用包名、网站域名和标签；
- Android Credential Provider 创建的 Passkey，包括依赖方信息、用户标识、凭据标识、公钥、私钥和签名计数；
- 你选择导入的图片、二维码、CSV、加密备份和保险库文件；
- 通过局域网传输接收或发送的文件、图片和文本；
- 本地备份：在你选择的本机目录或外接 U 盘 / 硬盘上写入的加密保险库备份文件；
- 恢复密钥与紧急恢复信息：重新发放流程中生成的恢复密钥、密钥版本与创建时间；
- 主题、自动锁定时间、剪贴板清理时间、云端同步周期等本地偏好设置。

本应用不会主动读取通讯录、短信、通话记录、日历、设备广告标识，也不会持续收集或记录位置轨迹。仅在你点击地址模块的“使用当前位置”时读取一次当前位置。

## 三、本地存储与安全措施

保险库文件存放于应用私有目录，并使用基于主密码派生的密钥进行加密。4.0.0 起使用新一代 PMVE 加密容器：增量提交、块级加密、对象索引与完整性校验，并支持自动压缩，附件与媒体以加密对象形式存储。主密码仅在解锁和必要验证期间存在于应用内存，不以明文写入保险库文件。

本地备份功能通过系统文档选择器授权写入你选择的本机目录或外接 U 盘 / 硬盘。写入前应用会识别目标存储的唯一身份（如设备序列号、分区标识、卷标等），避免因盘符变化造成误覆盖；备份按你设定的周期覆盖写入源保险库文件，不执行同步。备份文件仅保存在你选择的目录中，卸载应用不会自动删除。导入或备份过程中因中断产生的临时文件会在后续启动时自动回收。

Passkey 私钥作为强制敏感字段存储在加密保险库中，不进入搜索索引、通知、剪贴板、日志或普通预览。Passkey 创建和签名仅由 Android 系统 Credential Provider 流程执行。

生物识别由 Android BiometricPrompt 和 Android Keystore 提供。本应用不会取得或保存你的指纹、人脸图像等生物特征原始数据。

扫描、分享等临时文件存放于应用缓存目录，并在后续启动时执行清理。通过局域网传输接收的文件、图片和文本会持久保存到系统公共下载目录（内部存储/Download/Vaultshare），以便你查看和管理；该目录中的文件由你及文件管理器控制，卸载应用不会自动删除。

系统备份已关闭，应用不会通过 Android 自动备份上传保险库文件。

应用默认对条目缩略图与图像预览进行模糊处理，通过所需验证后才显示原图；该保护与敏感内容的二次保护相互独立，关闭图像模糊不会解除敏感照片的验证要求。

应用默认使用 Android `FLAG_SECURE` 禁止主界面被系统截图、录屏或显示在最近任务预览中。你可以在安全设置中验证主密码并再次确认风险后关闭该保护；关闭后，系统、投屏工具、其他应用或旁观者可能保存屏幕上的敏感内容。自动填充认证、Passkey 凭据操作和同步扫码等独立敏感窗口始终保持截屏保护。

## 四、权限及用途

相关权限由具体功能在首次使用时按需申请，拒绝某项权限不会阻止保险库基本查看和编辑，但对应功能可能不可用。你可以随时在系统设置中撤销权限。

| 权限或系统能力 | 使用目的 |
|---|---|
| 相机 | 扫描动态码、Wi-Fi 二维码、同步二维码以及拍摄文档 |
| 图片和媒体 | 读取你主动选择的图片或附件，用于识别、导入或条目附件模块 |
| 通知 | 显示同步完成、局域网传输进度和前台服务状态提示 |
| 附近 Wi-Fi 设备 | Android 13 及以上读取当前 Wi-Fi 信息 |
| 大致位置或精确位置 | 由你主动触发时为地址模块填写当前位置；Android 12 及以下也用于读取当前 Wi-Fi 名称。你可以只授权大致位置，本应用不持续定位或记录位置轨迹 |
| Wi-Fi 状态 | 判断当前网络及辅助导入 Wi-Fi 信息 |
| 已安装应用列表 | 在关联程序选择器中显示可选应用和包名 |
| 生物识别 | 使用系统认证保护保险库解锁和敏感操作 |
| 网络访问 | 局域网同步与文件传输、用户主动连接的 WebDAV 服务、云端同步、检查更新以及启用时的在线泄露检测 |
| 前台服务 | 自动同步、局域网传输或云端上传下载期间在通知栏显示持续运行状态 |
| 自动填充服务 | 在你启用后向应用或网页表单提供你确认选择的凭据 |
| Credential Provider | Android 14 及以上创建、选择和验证 Passkey |

INTERNET、Wi-Fi 状态、生物识别声明和读取应用列表在部分系统中不显示标准运行时权限弹窗。自动填充服务及 Credential Provider 必须由你在 Android 系统设置中单独启用。

## 五、网络通信

### 1. 局域网同步与文件传输

当你主动扫描同步二维码、输入服务器地址或开启传输站时，本应用会与指定的局域网设备建立连接，交换加密保险库同步数据、条目更新时间和删除日志，或传输你选择的文件、图片和文本。同步与传输不经过开发者运营的中转服务器。

局域网通信仅接受 HTTPS，并校验二维码携带的临时证书 SHA-256 指纹。PIN 既不是请求参数，也不放在请求头：两端各自在本地把它作为 SPAKE2 口令参与密钥协商，网络上只传输一次性票据（ticket）。请注意同步地址与同步二维码本身内嵌了该 PIN，应把它视为敏感信息，仅向可信设备出示。你仍应仅连接可信设备，并核对同步地址及 PIN。通过传输接收的内容会保存到公共下载目录，见本政策第三条。

### 2. 在线泄露检测

在线泄露检测启用时，本应用会访问 api.pwnedpasswords.com。应用先在本地计算密码的 SHA-1 哈希，仅发送哈希值前 5 个字符，并在本地比对返回结果；完整密码和完整哈希不会发送。

该服务仍可能按照互联网通信的一般规律获得你的 IP 地址、请求时间、User-Agent 和哈希前缀。你可以在设置中关闭联网泄露检测，关闭后仅执行本地弱密码检查。

### 3. 用户授权的云端文件同步

云端功能默认关闭。启用后，你可以通过 Android 系统文档选择器，将加密保险库文件关联到用户选择的云端硬盘或其他文档提供程序。本应用不直接登录云账号，不保存云账号密码或 OAuth Token。

关联成功后，本应用会保存系统返回的目录 URI 或文件 URI，并申请持久读写权限，以便查找对应保险库文件及在你主动操作时执行同步或上传覆盖。同步会先读取文件、在本机解密和合并，再写回加密保险库并读回校验；上传覆盖会跳过合并，因此执行前需要用户明确确认。取消关联时应用会释放相应 URI 的持久权限并清除本地关联记录。

自动同步默认关闭。开启后，应用会按你选择的时间间隔（15 分钟至每周）在后台通过前台服务检查并同步已关联的云端文件或 WebDAV 服务器，同一目标连续失败多次时会自动暂停并在界面提示。自动同步仅在你主动开启后运行，可在设置中随时关闭。

具体云端服务或 WebDAV 服务器可能处理账号信息、IP 地址、请求时间和加密文件，其处理方式受对应服务商或服务器管理方约束。

你也可以通过 WebDAV 直接连接 NAS、Nextcloud、ownCloud 或其他自定义服务器。连接时，应用会向你填写的地址发送所选认证信息，包括用户名与密码、访问令牌、会话 Cookie 或客户端证书；上传和下载的保险库文件保持加密。服务器地址及认证配置由 Android Keystore 保护的密钥加密后存储。应用不会将这些凭据发送至所配置服务器以外的服务。

WebDAV 配置按保险库隔离。正式 Android 应用禁止明文网络通信；使用自签名 HTTPS 证书时，应用仅在证书 SHA-256 指纹与用户填写值完全一致时建立连接；应用不会提供忽略所有证书错误的选项。

### 4. 检查更新

当你在“关于”页面点击“检查更新”时，本应用会访问项目发布仓库（GitHub Releases API）查询最新版本，并按设备 ABI 选择对应安装包后直接在应用内下载。下载完成后，应用会校验安装包签名与当前版本一致，再通过系统安装器完成升级；Android 8.0+ 首次安装时需要在系统设置中允许“安装未知应用”。该请求可能包含你的 IP 地址、请求时间和 User-Agent；请求中不包含保险库数据。检查更新由你主动触发。

## 六、自动填充与 Passkey

启用自动填充后，Android 系统会在应用或浏览器请求凭据时调用本应用。只有在你解锁保险库并选择凭据后，相关字段才会通过 Android Autofill Framework 提供给目标应用或网页。

启用 Credential Provider 后，Android 系统会把 Passkey 创建或验证请求交给本应用。应用会校验依赖方域名与调用方，并在用户认证后生成或使用对应密钥。依赖方网站将收到 WebAuthn 协议要求的公钥凭据响应，不会收到 Passkey 私钥。

## 七、导入、导出、剪贴板与同步责任

你可以主动导出加密备份、原始保险库或明文 CSV。文件一旦保存到应用私有目录之外，其存储、分享、云盘备份和删除由你及目标应用控制。明文 CSV 不具备保险库加密保护。

复制敏感内容时，本应用会请求系统将剪贴板内容标记为敏感，并按设置的时间尝试清空。其他应用、输入法或系统组件在剪贴板有效期间仍可能访问该内容。

跨设备同步会将你选择同步的保险库数据和 Passkey 加密记录复制到另一设备。PC 客户端仅负责管理与同步 Passkey 数据，不执行 Passkey 签名。

## 八、第三方组件

本应用使用 AndroidX、Kotlin、Bouncy Castle、ZXing、CameraX、OpenCV、Google ML Kit（仅用于端上文字识别）、OkHttp 和 commonmark 等组件实现界面、加密、扫码、OCR、网络请求和文档渲染。二维码扫描与文档边缘检测完全在设备本地完成，不使用 Google Play Services 的扫码或文档扫描界面，也不联网。组件可能受各自许可和设备系统服务政策约束。

OCR、二维码解析和保险库加解密在设备本地执行。在线泄露检测与检查更新的外部通信范围见本政策第五条。

## 九、数据保留与删除

应用内删除条目时，条目会进入回收站并保留删除时间，以便恢复及跨设备传播删除状态。达到自动清理期限或执行彻底删除后，本应用会移除条目内容并保留必要的删除日志，用于防止旧设备在同步时恢复已删除数据。

清除应用数据或卸载应用会删除应用私有目录中的本地保险库和设置。已导出到其他目录、已同步至其他设备、已保存到公共下载目录、本地备份目录或已由其他应用保存的数据不会随本机卸载自动删除。

## 十、未成年人

本应用不是专门面向未成年人的服务，不建立用户画像，也不基于年龄投放内容或广告。监护人应根据设备使用情况决定是否允许未成年人保存敏感凭据。

## 十一、政策变更

隐私政策发生实质变更时，将更新本文件的生效日期，并随应用版本一并发布。新版政策自对应版本安装或更新后生效。

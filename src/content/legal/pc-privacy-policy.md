# 保险库 PC 隐私政策

> **生效日期：2026-07-14**
>
> 本政策适用于保险库桌面客户端，说明应用如何在本机处理保险库数据，以及何时与外部设备或服务通信。

## 核心原则

- **本地优先：**保险库数据默认保存在当前 Windows 用户的本地应用数据目录。
- **不做用户追踪：**应用不集成广告、行为分析、遥测统计或自动崩溃上报。
- **按需联网：**只有用户主动使用同步或在线泄露检测时，应用才进行对应的网络通信。
- **敏感操作由用户触发：**导入、导出、自动填充、同步覆盖和设备能力访问均由用户主动操作。

## 一、本地数据处理

保险库 PC 不提供开发者托管的账号或云端保险库。应用处理你主动录入或导入的以下内容：

- 账号、密码和动态验证码；
- 银行卡、证件、Wi-Fi、服务器和安全笔记；
- 自定义模块、关联程序及 Passkey 记录；
- 应用设置、加密索引和同步所需的必要状态。

### 摄像头、图片与位置

只有在你点击模块中的摄像头、图片识别或“使用当前位置”时，应用才访问对应设备能力。

- 摄像头画面、所选图片和 OCR 文字仅在本机用于填充当前条目；
- Windows 返回的位置结果仅用于当前操作；
- 应用不持续录制、不记录位置轨迹，也不会将这些内容发送给开发者。

## 二、加密与敏感数据保护

- 保险库使用基于主密码派生的密钥进行加密，主密码不会以明文写入保险库文件。
- 启用 Windows Hello 后，应用使用 Windows 提供的身份验证和 DPAPI 保护本机解锁材料，不读取生物特征原始数据。
- Passkey 私钥属于强制敏感字段，不进入搜索索引、日志、通知、剪贴板或普通预览。
- PC 客户端仅管理、备份和同步 Passkey，不执行 Passkey 创建或签名。

### 浏览器自动填充

启用浏览器自动填充后，浏览器扩展会识别 HTTPS 页面中的用户名和密码输入框，并根据浏览器提供的当前页面来源向本机 Native Messaging 宿主请求匹配条目。

**匹配与填充流程：**

- 未选择条目时，仅返回条目名称、用户名和随机条目标识；
- 用户选择条目后，才返回该条目的用户名和密码；
- 扩展不会在 HTTP 页面或来源不匹配的页面返回凭据；
- 保存和更新确认由本机窗口完成。

**在扩展中解锁：**

- 主密码会短暂进入扩展弹窗和后台进程内存，并通过 Native Messaging 发送给本机宿主验证；
- 主密码不会写入扩展存储、日志或网页内容脚本，也不会发送至开发者服务器；
- 弹窗关闭或请求结束后会清空输入值；
- 用户仍可改用本机解锁窗口或 Windows Hello。

**私有网络来源：**

- 私有和回环 IP 来源必须由用户在本机逐个授权完整的 IP 与端口；
- 授权记录附带本机完整性签名，并可在设置中撤销；
- 公网、链路本地、组播和未指定 IP 不允许授权。

当用户在页面中主动选择“保存当前填写内容”时，当前用户名和密码会通过浏览器与本机宿主之间的 Native Messaging 通道写入本机保险库，不会发送至开发者服务器。

取消浏览器关联会删除当前 Windows 用户的本机宿主注册和应用生成的扩展副本。浏览器中已经安装的扩展仍需通过对应浏览器自行移除。

### 原生程序自动填充

启用原生程序自动填充后，应用仅在用户按下全局快捷键时：

- 读取当前前台 Windows 程序的进程名称、窗口标题及 UI Automation 暴露的输入控件属性；
- 使用这些信息匹配已关联的登录条目，并判断账号和密码字段；
- 通过 Windows UI Automation 将账号与密码直接写入目标控件。

该过程不经过剪贴板、不自动提交，也不会把凭据发送至开发者或第三方服务器。应用不会持续记录窗口标题、输入内容或用户按键；不匹配关联程序时不会提供保险库数据。

## 三、网络通信

### 局域网同步

只有在你主动开启同步服务时，应用才监听本地网络端口，并与持有当前二维码和 PIN 的设备交换保险库同步数据。服务使用每次同步临时生成的 HTTPS 证书，二维码包含证书 SHA-256 指纹供移动端固定校验；PIN 仅通过请求头提交，不写入实际同步请求地址。同步不经过开发者运营的中转服务器。

### NAS 与自定义云同步

当你主动启用 WebDAV 云端同步时，应用会连接你填写的 NAS 或自定义服务器，并向该服务器发送：

- 加密保险库文件；
- 你选择使用的认证信息，例如用户名与密码、访问令牌、会话 Cookie、客户端证书或 Windows 域凭据。

保存的认证配置使用当前 Windows 用户作用域的 DPAPI 加密。应用不会把该凭据发送至所配置服务器以外的服务。

WebDAV 仅接受 HTTPS，配置按保险库谱系隔离。使用自签名证书时，只有证书 SHA-256 指纹与用户填写值完全一致才允许连接，应用不会无条件忽略证书错误。

### 云端硬盘文件关联

当你关联 OneDrive、Dropbox、坚果云或其他云盘客户端同步目录中的 `.pmv` 文件时：

- 应用仅通过 Windows 本地文件系统读写该文件；
- 应用不直接登录云盘账户，也不获取云盘 OAuth 令牌；
- 文件上传、下载、版本保留及跨设备分发由对应云盘客户端和服务提供方完成。

云端硬盘关联路径按保险库谱系保存在本机。默认同步会先读取远端文件、在本机解密和合并，再覆盖写回加密保险库；上传覆盖会跳过合并，因此执行前需要用户明确确认。

### 在线泄露检测

启用联网检测时，应用访问 Pwned Passwords 服务：

- 仅发送密码 SHA-1 哈希的前 5 个字符；
- 完整密码和完整哈希不会发送；
- 返回结果在本机完成比对；
- 服务提供方仍可能获得 IP 地址、请求时间和哈希前缀。

你可以随时关闭联网检测。

### 赞助与支持

应用在设置中提供"赞助支持"入口，点击后通过默认浏览器打开项目赞助页面。应用不收集、不处理、不传输任何与赞助相关的金额、支付凭据或第三方支付账号信息。

## 四、导入、导出与剪贴板

- 你可以主动导出加密备份、原始保险库或加密压缩包；
- 文件保存到保险库目录之外后，其访问、分享、云盘备份和删除由你及目标软件控制；
- 加密压缩包内含可迁移的数据文件，导出时由用户设置的口令进行 AES-256 加密；
- 复制敏感内容后，应用会按照设置尝试清理剪贴板，但其他本机程序在清理前仍可能读取剪贴板内容。

## 五、同步与删除

- 条目进入回收站时会保留删除时间；
- 彻底删除后，应用会保留必要的删除日志，防止旧设备在后续同步时恢复已删除数据；
- 删除本地保险库文件或卸载应用，不会自动删除已导出的文件、其他设备上的同步副本或第三方云盘中的副本。

## 六、第三方组件

应用使用 Python、PySide、OpenCV、RapidOCR、Windows Runtime、WebExtension Native Messaging、系统密码学组件及其他随应用分发的依赖，实现界面、加密、自动填充、摄像头、OCR、定位和导入功能。

除在线泄露检测及用户主动发起的同步外，这些功能均在本机执行。

## 七、政策变更

政策发生实质变化时，应用将更新生效日期，并随对应客户端版本发布。

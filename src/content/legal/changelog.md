# Android 更新日志

仅记录保险库 Android 客户端的功能与修复。桌面端变更在其独立仓库维护。

---

## 4.6.1 - 2026-09-23

### 新增
- 离线扫描：文档边缘检测与透视校正改用 OpenCV，二维码取景改用 CameraX + ZXing，**移除 Google 文档扫描与 Code Scanner 依赖**（不再要求 GMS 设备，扫描全程在本地完成）。
- 图像模糊：新增「图像」设置，详情页缩略图与图像预览默认模糊，通过所需验证后才显示原图。
- 标签：批量添加支持多标签（统一解析中英文逗号、空格与换行）。
- 卡证日期：输入与显示归一化（`YYYY-MM-DD` / `MM/YY`），新增「长期」存储哨兵。
- 密码健康：改用 zxcvbn 评分判定弱密码。
- 滚动：新增视觉回弹，替代平台拉伸效果。

### 改进
- 拍摄画质：改用 `CAPTURE_MODE_MAXIMIZE_QUALITY`（此前跳过 3A 收敛，常拍到未合焦帧）；显式锁定 4:3 且优先高分辨率；裁剪源上限 1800 → 3000；复核屏产物不再被二次重压。
- 相机倍率按钮按预览画面底边定位，落在画面内部而非黑边。
- 二级页标题统一居中；安全列表页数量改为换行副标题并与标题同色；帮助图标补右侧安全边距并放大点击热区。
- 后台任务通知全程可见，不再随进入前台被撤销；终态通知在前台也会提示。
- 剪贴板：进程回收后回前台补偿清理过期敏感内容；清理时限可配置（0–600 秒，`0` = 不清理）。
- 底部导航「库维护」改为「整理」。

### 修复
- 底部弹窗（选择关联应用 / 选择关联填充 / 选择模块）被绘制到屏幕顶部的回归。
- 存储：合并写回改为流式复用源容器，不再全量重写；新增对象清单只读描述符。
- 安全（逐条状态见 `SECURITY_AUDIT_2026-09-23.md` 第 0 节）：外部操作标志可能永久绕过自动锁；跨账户待确认导入未绑定目标库；CSV 公式注入；WebDAV 凭据进入 saved-state；WebDAV 客户端缓存键含明文私钥；依赖解析仓库边界。
- 构建：`gradle/verification-metadata.xml` 缺两条校验和导致联网构建必然失败；`org.gradle.jvmargs` 2g → 4g（release 打包与测试在同一次调用时会 OOM）。

### 清理
- 删除 `docs/` 目录（43 份计划与设计稿）与仓库内临时日志；删除已过时的跨端图标规范与 OTP 规范（`spec/icons/`、`spec/OTP_SPEC.md`）。

## 4.5.0 - 2026-09-14

### 新增
- 自动填充排除项写入 PMV，导出、同步和迁移保险库时随库保存并在导入后恢复。

### 改进
- 普通弹窗恢复与回收站共用的全窗口背景模糊与变暗，覆盖底部导航区域及输入法收起后的布局；自动填充弹窗保持原样。
- 主页新增按钮与选择器按右边缘定位，预留 8dp 间距，选择器上下滚动提示保留固定留白。
- 主页排序归位动画的目标横坐标限制在左右安全边距内，避免松手时贴住屏幕左侧。
- 更新卡片在版本说明、下载、校验、安装权限与错误状态之间替换内容并重新布局，避免文案和进度条重叠。
- 导入 PMV 前检查可读性、大小、格式与冗余文件头，再进入账户命名；非法名称或重名时保留命名窗口并显示错误。
- 用户名菜单按内容确定宽度，切换用户菜单至少与按钮同宽；公共下拉菜单统一最大宽度为 360dp，切换用户菜单上限为 320dp。
- 统一弹出式卡片模板、背景模糊、关闭按钮与滚动提示效果。
- 优化主页分类卡片排序、单列悬浮边距及新增 FAB / 下拉选择器右对齐。
- 二级页面新增按钮与批量操作条统一高度，标签操作菜单按文本自适应宽度。
- 数据库临时文件清理和 PMVE 压缩改为后台自动维护，移除手动清理入口。
- 云端自动同步取消时正确结束等待回调，前台同步保留静默状态通知，避免上传回读流程假死或状态消失。
- 优化图片查看器显现动画、长期未修改文案及更多操作相关术语。

## 4.1.0 - 2026-08-29

### 新增
- 应用内更新：关于页“下载更新”直接在应用内下载 APK，校验签名与版本号后调用系统安装器升级，不再跳转浏览器；首次使用需在系统设置中允许“安装未知应用”。
- Markdown 渲染升级为整文档 Web 视图（WebView）：支持 Mermaid 流程图/时序图等图表离线渲染；渲染端做 HTML 消毒并限制脚本来源与远程请求，防止注入与外联。
- Markdown 查看器重构：样式与交互抽离为独立 assets 资源（markdown.css / viewer.js），经 WebViewAssetLoader 以 https 同源加载；Mermaid 图表按图独立容器（mermaid-card）+ 工具栏（适应 / 重置 / 全屏），支持正文滚动优先手势（未放大时单指滚动页面、双指捏合、双击缩放；放大后单指平移）；图表可进入原生全屏查看；代码块一键复制（沿用剪贴板 TTL 自动清空）、宽表格横向滚动。
- Markdown 查看器支持范围精简：仅支持标题 / 文本格式 / 列表 / 任务列表 / 表格 / 引用 / 代码块 / 图片 / Mermaid 与内部导航（自动目录 + #anchor 页内跳转）；外部 URL、邮件、电话、文件路径、跨文档链接与自定义 scheme 一律忽略不跳转（保险库内容不外发）。
- 修复 Mermaid 图表未渲染问题：代码块复制按钮注入污染了图表源码导致解析失败，现跳过 Mermaid 代码块。

### 改进
- 动态码（OTP）按时间窗缓存派生结果，避免每秒重复解密与 HMAC 计算造成的界面卡顿。
- 自动填充来源列表按保险库内容引用记忆化，输入与同步心跳不再触发全库解密。
- 泄露检测的全库解密从主线程移至 IO 线程，解锁与手动检测时界面不再卡死。

## 4.0.0 - 2026-08-14

### 新增
- 新一代 PMVE 加密容器：增量提交、块级加密、对象索引、媒体与附件对象化存储、自动压缩，支持大数据量与超大文件，并带完整性校验。
- 局域网通信升级：Spake2 双向认证、二维码 / PIN / 证书指纹校验、传输站按连接类型自动识别（导入确认 / 同步 / 文件传输）。
- 云同步双目标独立：云端硬盘与 WebDAV 独立关联、独立自动同步周期与失败计数，互不干扰。
- 本地备份：可选择本机目录或外接 U 盘 / 硬盘，按周期（实时至每月）自动覆盖写入；基于设备唯一身份识别目标盘，避免盘符变化导致误覆盖。
- 恢复密钥与密码重置流程重构：恢复密钥重新发放与保存、验证后立即解锁并进入改密流程，旧密钥在新密钥确认前保持有效。
- 中英文界面全量覆盖：硬编码文案迁移至 Android 标准资源，切换语言即时生效。

### 改进
- 自动填充：索引化匹配、应用名称兜底显示、无匹配时提供密码生成并填充、Inline Autofill 兼容回退。
- Markdown 模块：多行文本升级为 Markdown，支持全格式渲染、编辑 / 查看切换、详情页格式化查看与一键复制。
- 高清图像查看：屏幕预览 + 可视区域解码、双击两级放大、多图滑动切换，超大图内存可控。
- 安全设置：截屏保护与后台界面隐藏拆分为独立开关；敏感操作窗口始终启用 FLAG_SECURE。

### 修复
- 云端自动同步开关被另一个目标的轮询 / 共享配置覆盖的问题。
- 复制证件号等敏感内容时提示文案未随语言切换的问题。
- 证件类型下拉框切换语言后仍残留中文的问题。
- 解锁成功动画重复播放圆环填充的问题。
- 导入大量图片 / 附件后详情页图像丢失、占位提示未居中等问题。
- 局域网导入 / 同步 / 文件传输的连接校验、超时与结果弹窗问题。

- 自动同步 `load()` 读取新 per-target key 失败时回退旧 key，确保 3.6.3 → 3.6.4 升级不丢配置。
- `put()` 方法中 If-Match 头对非 HTTP 标准 ETag（如 `*`）的支持。
- `CloudCredentialStore.createDirectories` 默认值 `true` → `false` 与 UI 开关保持一致。
- 自动同步 `runAutoCloudSyncIfDue` 中 `cloudSyncRunning` 检查位置提前可能漏检的问题。

## 3.5.0 - 2026-07-14

### 新增
- WebDAV 新增 OAuth 2.0 访问令牌、Cookie / Session 与 PKCS#12 客户端证书（mTLS）认证；Android 无通用域凭据接口时会明确拒绝 NTLM/Kerberos，不再产生假连接。

- 设置页展开卡片移除黑色直角波纹，改用圆角裁剪的低透明度主题色按压反馈，并扩大标题点击热区。

## 3.4.3 - 2026-07-14

### 新增
- 新增通过 Android 系统文件选择器上传加密保险库到用户选择的云端硬盘。
- 云端同步新增 NAS 与自定义 WebDAV 直连，连接前验证服务器与认证信息，上传后读回并解密校验。
- WebDAV 凭据使用 Android Keystore 加密存储，并支持主动断开和清除本地凭据。
- 密码检测卡片新增风险、重复及低安全密码统计，并可查看对应条目。
- 保险库维护新增重复条目对比确认，不再直接执行合并。
- 新增安全笔记、服务器和自定义类别。
- 新增可自由组合、排序并设置敏感属性的条目模块。

- 首次启动时按系统版本集中申请相机、图片和 Wi-Fi 读取所需的运行时权限。
- 自动填充扩展到浏览器网页，并继续支持关联应用匹配。

- 新增永久删除日志，确保彻底删除可以跨设备传播。

### 改进
- 应用内部命名空间由 `com.passmanager` 统一迁移到 `com.vault`，对外应用 ID 保持 `app.fae.vault`，现有安装和数据目录不变。
- 网页自动填充补充来源元数据解析、目标包身份校验和登录表单保存候选提取，降低浏览器多字段及错误来源误填风险。
- NAS / 自定义云关联改为填写 WebDAV 文件夹地址，程序按当前账户生成 `vault_用户名.pmv`；旧版完整文件地址会自动转换为父目录显示。重新关联和取消关联继续强制验证当前主密码，取消关联后仍需二次确认。

- 自定义内容中的银行卡和证件模块新增跨端 `images` 图片条目；相机或相册导入后自动 OCR，支持放大预览、单张删除、重复过滤和 8 张上限。
- 启用云端同步需验证主密码并确认已知晓风险；重新关联需验证主密码，取消关联需验证主密码并二次确认，取消关联不会删除远端保险库文件。

- 云端目录关联新增文件删除、同名替换、多个同名文件及远端元数据变化检测；异常时阻止自动重建或覆盖，并提示重新关联。

## [2.3.0] — 2026-06-22

### Added — 自写文档扫描相机（非 GMS 设备）

- 新增基于 CameraX 的 `CameraScanActivity`，替代以前调系统相机的兜底路径
- 实时取景：CameraX `ImageAnalysis` 抽 YUV Y 通道走自写边缘检测，按预览 letterbox 在画面上画黄色矩形描边，5–10 帧贴住文档轮廓
- 复核 / 手动裁剪：拍照后进入复核屏，初始裁剪框 = 取景时最后一帧检测到的 ROI（按 `rotationDegrees` 归一化到显示朝向）；用户可拖 4 角独立缩放或在框内拖动整体平移；最小尺寸 6%，确认后才生成裁剪 JPEG 并返回

### Added — 中文拼音排序与索引

- `Entry.titleSortKey` 缓存属性接入 ICU `Han-Latin; Latin-ASCII; Lower` 转写：「苹果」键 = "ping guo"，与「Apple」混排时按拉丁字母统一比较
- 主列表 `VaultOps.sortedByTitle` 改用 `titleSortKey` 排序；侧边字母索引 `initialOf` 按拼音首字母分组（苹果 → P，百度 → B），不再全部塞进 '#'
- 转写器全 App 单例（ICU `Transliterator` 只读线程安全）

### Changed — 文档边缘检测算法重写

- 自适应阈值从「max·25%」换成「投影内部 5–95% 中位数 × 1.8 + 绝对地板 800」：单点高光不再把阈值拉爆漏检弱边
- Sobel 改为分通道投影：`|Gx|` 沿列累加只用于找左右边、`|Gy|` 沿行累加只用于找上下边——卡内多为水平文字 strokes（贡献 `|Gy|` 中段），不会再被左右边检测误判
- 找边方式从「从外向内首个超阈值像素」改为「外缘 45% 区域里 argmax + 阈值校验」：内部纹理偶发超阈值不再被当成卡边
- 新增 3×3 均值滤波 + 1D 投影平滑（radius 3）抑制单像素噪声

### Changed — 静态二维码识别去 ML Kit

- `WifiQr.scanFromUri` 改用 ZXing 本地解码（`MultiFormatReader + HybridBinarizer` + 反色二次尝试 + >1600px 自动 sub-sample 抗 OOM）
- 移除 `com.google.mlkit:barcode-scanning:17.3.0` 依赖；GMS 实时扫码界面仍由 `play-services-code-scanner` 提供，`Barcode.FORMAT_QR_CODE` 由其传递依赖 `barcode-scanning-common` 提供

## [2.2.0] — 2026-06-15

### Added (Sync v2 — 多端双向同步基础设施)

- 库 schema 升级：`VaultPayload` 增加 `syncMeta.deviceId`（库首次创建时分配的 UUID）与 `exportEpoch`（每次落盘刷新的本地时钟）
- 加密备份 `.pmbak` 导入改走 **LWW（Last-Writer-Wins）合并**：按 `id` 匹配、按 `updatedAt` 比较；同秒并发自动 KEEP_BOTH，不再需要用户选 OVERWRITE / SKIP
- 删除走 **墓碑（tombstone）** 机制：`Entry.deletedAt` 标记删除时间，墓碑条目随同步传播，让"在 A 删除的条目"能传到 B 自动删除
- "复活"语义：A 删除后 B 在更晚时刻编辑过 → 合并后条目恢复为 B 的版本
- 时钟漂移校准：合并端按 `localNow - exportEpoch` 计算 skew，把远端时间戳翻译到本地基准
- 设计与互操作规范见 `spec/SYNC_V2.md`；跨端测试向量 `spec/sync_v2_fixtures.json`

### Changed

- 删除条目不再"移到回收站表"，而是在原列表上打 `deletedAt` 墓碑标记；UI / 搜索 / 排序自动过滤
- `VaultListScreen` 主列表、条目计数、标签来源都改为只看活跃条目
- `VaultListScreen` 顶栏回收站 badge 改为统计 `entries` 中 `deletedAt != null` 的条目数
- CSV 明文导出不含墓碑条目
- 设置页 ImportPolicyDialog 不再用于 .pmbak 导入（LWW 不需要），仍保留给 CSV 导入路径

### Migration

- 老 v1 库首次以 v2.2.0 解码时自动迁移：
  - 老 `trash` 数组合并进 `entries`（保留 `deletedAt`），清空 `trash`
  - 生成 `syncMeta.deviceId`
  - 下次保存即落盘 v2 格式

### Tests

- `VaultOpsTombstoneTest`（6）：墓碑 delete / restore / purge / purgeAll / purgeExpired
- `SyncV2MergeTest`（10）：spec 中 8 个核心场景 + 时钟校准 + 综合统计
- `SyncV2IntegrationTest`（2）：v1→v2 端到端 + GC
- `VaultCryptoTest`（6）：含新增 exportEpoch 与 deviceId 迁移用例
